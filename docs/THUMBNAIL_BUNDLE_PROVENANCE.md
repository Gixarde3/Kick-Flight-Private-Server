# Disc thumbnail placeholder provenance

The original screenshot-derived bundles for these five disc thumbnails were absent from the checkout, and the
`../Disc_data/thumbnail_source` images needed to reproduce them were also unavailable. To make their existing CDN
routes usable, `config/resources/catalog.json` now points at the valid Unity bundles generated by
`scripts/build-disc-thumbnail-bundles.py`'s deterministic neutral-art fallback. These are placeholders, not original
game art. The fallback assets are already present under `content/resources/ui-disc/`.

The table preserves the old catalog identities and integrity metadata so the screenshot-derived assets can be
restored later. The old size, CRC32, and MD5 values are those advertised by the previous Octo resource-list
fixtures. The `md5` suffixes are part of the bundle filenames. Current sizes and hashes describe the served
placeholder bytes; `scripts/build-title-resource-catalog.py` regenerates their Octo metadata from these source paths.
These five bundles are explicit tracked exceptions to the repository-wide `*.bundle` ignore; the same allowlist
tracks the nine generated `aedNNN` bundles required by `MatchingScene`, so a fresh clone contains all 14 local
runtime dependencies without needing the external asset repositories.
