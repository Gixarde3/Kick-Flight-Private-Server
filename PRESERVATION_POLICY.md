# Política de preservación

- `C:\Users\Gixar\Documentos\Variedad\Kick-Flight-Assets` es una fuente externa de sólo lectura. Este repositorio no la modifica ni la incorpora como submódulo.
- `base.apk` se ejecuta desde la fuente y debe conservar SHA-256 `F79F1B48F86C4F5973C763CBC6C166BD6C42CC83D4E36ECA75D7D1CAB74AD8D1`.
- APKs, bundles, assets, dumps completos, claves privadas, certificados locales y capturas con identificadores están excluidos por `.gitignore`.
- Sólo se incorporan esquemas derivados, fixtures mínimos y evidencia redacted necesaria para reproducir hallazgos.
- No se usan tokens, API keys ni firmas históricas. Los valores futuros del servicio comunitario deberán ser nuevos y locales.
- No existe proxy upstream hacia infraestructura histórica. Los endpoints desconocidos fallan de forma local y explícita.
- Este repositorio no declara licencia pública; esa decisión queda reservada al usuario.
